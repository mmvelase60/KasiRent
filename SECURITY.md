# Security status

KasiRent is a local MVP with known hardening and recovery gaps. No public security contact or vulnerability-disclosure program has been established.

[Security architecture and threat model](docs/09-Security/KR-SEC-001-Security-Architecture-and-Threat-Model.md) records current controls. [Deployment readiness](docs/12-Deployment/KR-DEP-001-Deployment-and-Release-Readiness.md) lists public-operation gates.

Report suspected issues privately to the project owner through an existing trusted channel. Include a synthetic reproduction, affected version and expected behaviour. Do not post renter records, passwords, tokens or connection strings in public issues. Do not test against another landlord's live records.
